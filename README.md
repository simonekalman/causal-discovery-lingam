# Causal Discovery under Non-Gaussianity

This repository contains a Python-based Monte Carlo study of the robustness of DirectLiNGAM under violations of its key identifying assumptions.

## Overview

The project studies when DirectLiNGAM correctly recovers the causal direction in linear non-Gaussian models, and when it fails under dependent disturbances.

The simulations analyze Gaussian benchmarks, non-Gaussian independent shocks, common latent volatility, and mean-independence violations.
